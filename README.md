# Dr. Mohan Kulkarni — Advanced 3D Dental Practice Website

A state-of-the-art dental clinic web application engineered with Vite, React 18, TailwindCSS, and Three.js.

## Key Features
- **Interactive 3D Dental Engine**: Real-time Three.js 360° rotational anatomical tooth and Swiss titanium implant model with physical shader translucency and layer peeling.
- **Virtual 3D Smile Studio**: 3-step interactive smile assessment quiz calculating personalized treatment roadmaps.
- **Clinical Gallery**: Interactive before-and-after touch & drag sliders for porcelain veneers and implants.
- **Full Service Directory**: Implantology, Digital Smile Architecture, Invisalign, Microscopic RCT, and Laser Periodontics.
- **Priority Appointment Scheduler**: Multi-step triage flow with direct WhatsApp confirmation and reference tokens.
- **Practice Centers**: Flagship Bandra West Studio & South Mumbai Marine Lines Implant Center.

## Tech Stack
- **Framework**: Vite + React 18 + React Router 6
- **3D Graphics**: Three.js
- **Styling**: Tailwind CSS + Glassmorphism
- **Icons & Motion**: Lucide React + Framer Motion + Canvas Confetti
